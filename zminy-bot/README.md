# zminy-bot - робочі файли для сервера

Лише те, що потрібно, щоб оновити бота на сервері: `bot.py`, `picture.py`,
`Dockerfile`, `compose.yml`. Тести, зразок таблиці й налаштування сюди не
викладені, бо цей репозиторій публічний, а вони містять справжні імена й
графік. Налаштування (`.env`) лежать лише на комп'ютері власника й на сервері.

Оновлення (з папки бота на комп'ютері власника, де є `.env` і ключ від сервера):

    scp -i ~/.ssh/<ключ> bot.py picture.py Dockerfile compose.yml <користувач>@<сервер>:zminy-bot/
    ssh -i ~/.ssh/<ключ> <користувач>@<сервер> "cd zminy-bot && docker compose up -d --build --force-recreate"
